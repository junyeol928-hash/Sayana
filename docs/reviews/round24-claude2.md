## 4. SOTD に届かない理由(効き目の大きい順)

### 2. 答え合わせの帯が、いま押した選択肢の上に出る

- 画面: m-sticky-before-tap → m-sticky-after-tap(4 つ目の選択肢を押した直後。選んだ丸も文字も帯の下)、m-review-chosen(撮影。2 つ目の選択肢が帯で半分隠れ、帯の下の 4px に選択肢の枠がのぞく)

### 7. 暗い表示の断り書きと、褐のマスの二重の意味(見送りの判定)
