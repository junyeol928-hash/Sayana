# 11 回目の審査(Claude・作業の経緯を知らないサブエージェント)

対象: `docs/screenshots/round11/`(16 枚)と `docs/screenshots/offline/`、ソースと `docs/design.md`。凍結したコミット 32a6113 で審査した。

## 点数
Design: 8.1 / Usability: 8.0 / Creativity: 7.7 / Content: 8.3

## 良いところ(3 つまで)
- 「5 段の染まり × 刺し子の目の形」が、ヒーロー・部と章で区切った地図・凡例・メタ行・段のボタンまで同じ言葉と形で通っている。暗い表示の褐は藍白の四角の目で「仕上げた札」として立っている(10 回目の指摘は直った)。
- 教材として芯が強い。仕事のコードの番号の札と直後の注、PC でコード 15px・注 14px の主従、正解に藍の丸とレ点と「✓ 正解」、エラーメッセージを途切れない 1 ブロックで。
- オフラインを本当に検証している。ループの図はスマホの幅で 1 画面に収まり、14px のまま読める。

## 直すべきところ(重要な順)
1. **読解のコードで、コメントがまだ割れる** — 収まらないコメントは `break-word` で切られ、`);` が生きたコードの行に見える。続きの行の印もない。直し方: 続きの行に行番号の列で見える印を付ける、コメントの範囲を色の面で囲む。
2. **オフラインを「警告」として見せていて、「全部読める」が消える** — 朱の点で「オフライン」。オフラインでも「質問」が同じ重さで残る。直し方: 保存がそろっていれば藍の点で「電波なし・保存済み」、朱は欠けがあるときだけ。オフラインの間は質問を弱く。
3. **段の順が「染まりの順」になっていない** — 合格後の主ボタンは「読解へ進む」なのに、ヒーローと下の行は「演習ができたら藍に」。読解は染まりの条件に入っていない。直し方: 段の順を クイズ → 演習 → 読解 にするか、読解を条件に入れる。
4. **PC のヘッダーと本文に「AI OFF」など開発者向けの状態が漏れている** — 直し方: ヘッダーとレッスン冒頭から消し、AI の入口の中だけで知らせる。
5. **PC のレッスン一覧の「まだ」の印「- -」が欠けた値に見える** — 直し方: 「まだ」には印を置かない。
6. **暗い表示で、最初のご褒美の甕覗きがほとんど見えない** — 直し方: 縹より弱い順は保ち、面と縁を少し明るく。
7. **見せ場が色見本の帯に偏り、ほかの画面はありがちな「整った UI」に戻る** — 直し方: 署名の要素をもう 1 つ(採点の「4 / 5」を刺し子の目の数で見せる、見出しの書体、布の耳のような区切りなど)。
8. **ヒーローの言葉と組みの細部** — 「続きから(クイズ)」の括弧が硬い、ふりがなで間が空く、層がまだ多い。直し方: 「クイズの続きから」など。
9. **呼び名と用語集の小さな不一致** — 「ダッシュボード/用語集」と「ホーム/用語」。英語の名前が見出しと同じ語を繰り返す。直し方: 名前をそろえる、同じ綴りなら英語の名前を出さない。
10. **「連続 0 日」を出している** — 直し方: 0 日のときは出さない。
