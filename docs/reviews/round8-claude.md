対象: `docs/screenshots/round8/`(16 枚)と `docs/screenshots/offline/`、ソースと `docs/design.md`。凍結したコミット b9763dd で審査した。

## 良いところ(3 つまで)
- 「藍の稽古着」のコンセプトが、色・形・言葉の三つで最後まで通っている。5 段の染め(生成り→甕覗き→縹→藍→褐)には刺し子の目の形(1 本・2 本・四角)が付いていて、ふりがなと意味の文字も添えてある。区切りの刺し子の破線、部の縦書きの札、段の並びの下の縫い進む線も同じ系統でそろっている。スマホ、PC、暗い表示のどれで見ても同じアプリだと分かる(m-home-lower / m-home-dark-lower / pc-dashboard)。
- 「仕事のコード」の見せ方が教材としていちばん強い。説明のある行は番号を札にして行を明るくし、説明をその行の直後に挟んでいる。折り返した行は行番号の列より右から始まる。`@RequiredArgsConstructor` が final フィールド 4 つを注入すること、Clock を Bean にするとテストで時刻を固定できることなど、現場のコードを読む人に必要な説明が、必要な行にだけ付いている(m-lesson-atwork / pc-lesson-atwork)。
- オフラインの確認が、主張だけでなく撮影と JSON で裏付けられている。キャッシュ 99 件、図 1、読解 20、用語 374(offline-check.json)。前回の指摘も多くが直っていた(図の文字 14px、用語集の「で」、索引の下の帯、名前の「クイズ/演習」へのそろえ、PC のヘッダーの不透明化、ハルの名札の面、JDK 21 の前提)。

## 直すべきところ(重要な順)
1. **図の最初の見え方が、幹の途中で切れている(スマホ)** — offline-lesson-figure.jpg、`mobile/app.js` 1535 行、`app.css` 502 行。SVG の真ん中を見せているが、ループの図は戻りの線が右にあるので幹が右にずれ、「初期化」「条件式」が右のフェードで切れる。左は mask がなく箱が硬く切れる。折り返しが語の途中で起きている。直し方: 最初のノードの中心を見せる、左の mask は scrollLeft > 0 のときだけ、ラベルに `<br/>`、「全体を見る」を付ける。
2. **PC の「続きから(確かめる)」が古い名前のまま** — label を localStorage に保存して表示している。撮影スクリプト・`mobile/index.html` の description・manifest にも「読む・確かめる・書く」。直し方: 表示のたびに section の id から名前を引く。
3. **採点後、正解の選択肢にだけ目に見える文字がない** — 誤答には「× あなたの答え」、正解は藍の枠と小さなレ点だけ。直し方: 正解にも「✓ 正解」を藍で。解説の箱の「正解: 〜」は削るか短くする。
4. **ホームの染まりのマスが、ただ 55 個並んでいるだけで地図になっていない** — 部・章の切れ目がない。直し方: 部ごとに行を分け一〜四の札、章の切れ目は 4px、押すとレッスン(か部)へ、前回の続きのマスに朱の印。
5. **暗い表示で、いちばん浅い段がいちばん目立つ** — 甕覗きが最も明るく、褐は明るい縁で「選択中」に見える。直し方: 甕覗きは沈んだ面に縁程度、目立ち方(彩度・刺し子・白の量)は段が深いほど強く。
6. **スマホのヒーローの要素が多く、最初の画面の 6 割強を使っている** — 8 層。直し方: 「次の新しいレッスン」を外す、保存の状態は保存済みならヘッダーの小さな印に。
7. **難しさの印に、染まりのマスと同じ藍の四角を使っている** — 直し方: 弱い色の線か高さの違う棒。
8. **「読む 15 分」が 55 レッスン中 53 で同じ** — 直し方: 本文の文字数とコードの行数から計算する。
9. **用語集の読みの表記ゆれと、PC の格子の穴** — EOF・null・NullPointerException・enum の読みがひらがな。PC は 3 列の格子で行の高さが引っ張られる。直し方: 表示の読みをカタカナに、PC は `columns` に。
10. **PC の段の並びの右端に、薄い縦の帯が出ている** — 7 段が収まっているのにフェードが常に出る。直し方: `scrollWidth > clientWidth` のときだけ。

## 8.5 に届くには
- Design: 暗い表示の目立ち方、染まりのマスの構造化、図を既定の白い箱から藍の面と刺し子の矢印に。見出しだけでもキャッシュした Web フォントにすると札の声が立つ。
- Usability: 図の最初の見え方と全体表示、正解の文字、ヒーローの整理、古い名前の一掃。
- Creativity: マスを部の地図にすること、部を卒業したときに部の札が染め上がることなど、コンセプトが画面の構図に出る瞬間を 1 か所作る。
- Content: 所要時間を本当の値に、読みの表記をそろえる、図のラベルを語の切れ目で改行。中身(現場のコード、版の違いまで書いた解説、読解 171 問、用語 374 語)はすでに高い水準。
