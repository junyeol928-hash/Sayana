## 良いところ(3 つまで)
- コンセプトが見た目の仕組みまで届いている。藍の染め段階を進捗 5 段にし、麻の葉の刺し子を敷いた紺のヒーロー、刺し子の区切り線、縦書きの部の札まで、ひとつの比喩でつながっている。「進捗を色の深さで見せる」は間隔をあけた復習とも意味が合っていて、よくある AI っぽい学習アプリとはっきり違う。
- 教材が読者の仕事に合わせて書かれている。困りごとから入り「なぜそうなっているか」まで説明している。「仕事のコードではこう出てくる」は業務の Spring Boot コードの行番号と説明をつないでいて、目的に直接効いている。
- 下地の作りが丁寧。OKLCH で色相 245 にそろえた色、暗い表示の全トークン、本文 17px・行間 1.9、44px のタップ領域、`line-break: strict`、`prefers-reduced-motion`、Web フォントを使わないオフライン前提、`text-wrap: balance`。

## 直すべきところ
1. 署名の動き「染み込み」が目に入らない。冒頭の 18px の色見本だけが染まり、操作した場所(読了・合格・復習)は画面の外。古い色の上に新しい色が広がる形にもなっていない → 押した場所のそばで、古い色の上に新しい色を重ねて広げる。
2. 縫い進む線が「縫う」ではなく「伸びる」(scaleX で縫い目が縮む)。ページ全体のスクロールに連動していて本文の位置とずれる → clip-path / mask で範囲だけ広げ、レッスン本体に合わせる。
3. 「質問する」ボタンがずっと本文の上に重なる → 下へスクロール中は隠す・縮める。本文の下に余白。
4. 読解のコードが横にはみ出して読めない。PC は右の列が空いているのにコードが横スクロール → 折り返して ↪ の印、行番号。
5. 状態の四角がチェックボックスに見える。空のマス 48 個が申込用紙のよう → 生成りは弱い色の刺し子の破線に。ゴールの印も変える。段の並びは今の段を示す。
6. 段の並びが今の位置を示さず、後ろの本文が透けて濁る。ヘッダーと線が 2 本重なる。右端が切れて続きが分からない → 不透明に、線を 1 本に、右端にフェード、今の段に aria-current と下線、自動で横スクロール。
7. 暗い表示で染まり具合の意味が逆になり(卒業がいちばん明るい)、「読んだ」(L .40)が背景と約 2:1 で見えない → 彩度を段階の軸にし、卒業に白い刺し子の目を入れる。マス同士・背景と 3:1 を検算。
8. 同じ数字を何度も出していて見る場所が散る(復習 3 回、連続 2 回、正常時の「オンライン」)。補足の改行で行頭に「・」が残る。PC の連続 0 日が朱 → 数字の欄を別の数字に、ネット表示はオフラインのときだけ、0 は弱い色。
9. PC で AI が使えないとき、右の 380px が開発者向けの案内で埋まる → 1 列にして本文とコードに幅を回す。
10. 用語集が 405 語の平らな一覧で引きにくく、同じ語が別カードで重複して見える。索引がない。リンクが小さい。「モカ先輩」は捨てた珈琲の世界の名残 → 同じ語は 1 枚にまとめる、索引を固定、リンクを 44px に、名前の理由を design.md に書く。
