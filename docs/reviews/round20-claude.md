## 4. SOTD に届かない理由(効き目の大きい順)

Brilliant や Execute Program と並べたとき、問いに触れた瞬間の手触りでは、もう負けていない。手を止めての枠と、ほどける運針はこの道場にしかない。負けるのは、作り直した部品の**隣の画面**。読解の復習・1 日の終わり・PC の予定は、まだ前の世代の部品で組まれている。受賞作は「どの画面を開いても同じ手の仕事」に見える。上の 3 件は Design の「一部」を直接消し、1 件目は U5 と L3 も消す。

### 4. 「答えの前に置く」問いでも、答えが同じ画面に見えている

### 5. クイズと読解の誤答には、選んだ答えへの 1 文がない

### 6. 卒業の瞬間に、色が深くならない(9 点への余地)
