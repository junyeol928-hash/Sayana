# デザイン — 藍の稽古着

Java道場(スマホ版 `m/` と PC版)の見た目の決めごと。手順は design-direction スキル(コンセプト → モチーフ → 最小のデザインシステム → 3 案比較 → 参考との差分 → 検品)。
レビューの記録は [design-review.md](design-review.md)、画像の出典は [image-credits.md](image-credits.md)。

## 1. 目的と読者

- 読者は 1 人: 仕事で Spring Boot のコードを読む必要がある社会人。平日は通勤のスマホで読み、週末と仕事前に PC で手を動かす。
- 見る距離と時間: スマホを手元で 5〜20 分。電波のない地下鉄でも開く。PC はエディタと並べて 1 時間。
- いちばん大事なのは「本文が読みやすい」「次に何をやるかが 1 秒で分かる」「どこまで身についたかが見える」の 3 つ。

## 2. コンセプト

**稽古を重ねるほど、色が深くなる。**

藍染めは、布を甕(かめ)に浸けて引き上げるたびに色が一段ずつ深くなる。甕覗き(かめのぞき)→ 縹(はなだ)→ 藍 → 紺 → 褐(かち、「勝ち」に通じる)。
1 回で深い色にはならず、繰り返した回数がそのまま色に残る。間隔をあけた復習で身につけるこの道場の仕組み(読む → 確かめる → 書く → 復習 1・3・7・14 日)と同じ形をしている。

比喩の候補(最初の 1 つは捨てる前提で比べた):
1. 珈琲(今までのモカ先輩の世界) — 誰でも最初に思いつく。茶色とカップの絵文字で、学習の進み具合とつながらない。**捨てた**
2. 設計図・IDE・計測 — 等幅フォントと方眼の「記録・計測」型。AI っぽさを避けようとして逃げ込む新しい型。**捨てた**
3. **藍の稽古着** — 道場の稽古着(剣道着・柔道着)は藍染めの刺し子。染めの段階が「進み具合」に、刺し子の縫い目が「区切りと進行」に、そのまま使える。**採用**

## 3. モチーフ(8 軸)

| 軸 | 言葉 |
|---|---|
| 素材 | 厚手の木綿に藍を重ねた稽古着と、白い刺し子糸。マットで反射がない |
| 光 | 道場の高窓から入る拡散光。影はほとんど落ちず、奥行きは「色の段」で出す |
| 配色の出どころ | 藍の染め段階(甕覗き・縹・藍・紺・褐)と、晒し木綿の白。印(しるし)として朱を 1 点 |
| 構図 | 稽古着の合わせのように、左に 1 本の軸を通す非対称。縦書きの名札(部の札)を左の軸に下げる |
| 情報の優先順位 | ①今日の稽古(次のレッスン)②本文 ③染まり具合(進捗)④その他 |
| 余白 | 畳の目のように 4px の刻み。区切りは罫ではなく、刺し子のランニングステッチと余白 |
| 書体の声 | 落ち着いた太めのゴシック。道場の札のように、見出しは大きく短く。コードは読みやすい等幅 |
| 動き | 布に藍が染み込むように、色が中心からじわっと広がって止まる。弾まない。速く始まってゆっくり止まる |

様式は「主: 日本の工芸(藍・刺し子)× 副: スイス的な左揃えの格子」。和の記号(明朝・金・和紙)は重ねない。

## 4. デザインシステム(定数)

### 色(役割 × 段)。由来: 藍の染め段階と晒し木綿
OKLCH の色相 H は 245(藍色 237 と紺色 263 の間)で全段そろえる。

| トークン | ライト | ダーク | 役割 |
|---|---|---|---|
| `--bg` | 晒し `oklch(.985 .004 245)` | 褐 `oklch(.17 .025 250)` | 地 |
| `--surface` | 白 `#fff` | `oklch(.215 .03 250)` | 面(本文・カード) |
| `--surface-2` | 藍白 `oklch(.955 .014 245)` | `oklch(.26 .035 250)` | 一段沈んだ面・図の箱 |
| `--line` | `oklch(.88 .015 245)` | `oklch(.34 .03 250)` | 飾りの罫・刺し子 |
| `--line-strong` | `oklch(.62 .03 245)` | `oklch(.55 .035 250)` | 操作部品の枠(3:1 以上) |
| `--ink` | 紺 `oklch(.24 .05 255)` | 藍白 `oklch(.95 .012 245)` | 本文(15:1 前後) |
| `--ink-muted` | `oklch(.45 .035 250)` | `oklch(.78 .02 245)` | 補助の文字(7:1 以上) |
| `--accent` | 藍 `oklch(.45 .11 245)` | 縹 `oklch(.74 .10 240)` | 主操作・リンク・選択 |
| `--accent-soft` | 甕覗き `oklch(.93 .035 230)` | `oklch(.30 .05 245)` | 主色の薄い面 |
| `--shu` | 朱 `oklch(.53 .17 35)` | `oklch(.72 .14 40)` | 印: 不正解・注意・連続日数 |
| `--ok` | 青竹 `oklch(.52 .10 165)` | `oklch(.78 .11 165)` | 正解(文字とアイコンで示す) |
| `--code-bg` | 褐 `oklch(.20 .035 255)` | `oklch(.13 .02 255)` | コードの地(両テーマとも暗い) |

**染まり具合(進捗)の 5 段** — この道場の署名。レッスンの状態を色の深さで表す。どの段にも文字の名前を添える(色だけで伝えない)。

| 段 | 名前 | 状態 | ライト | ダーク |
|---|---|---|---|---|
| 0 | 生成り | まだ | 塗らず、弱い色の刺し子の破線 `oklch(.72 .02 245)` | 破線 `oklch(.42 .03 250)` |
| 1 | 甕覗き(かめのぞき) | 読んだ | `oklch(.88 .045 225)` + 縁 `oklch(.62 .08 230)` | `oklch(.6 .075 225)` |
| 2 | 縹(はなだ) | クイズ合格 | `oklch(.6 .11 240)` + 刺し子 1 本 | `oklch(.6 .1 238)` + 刺し子 1 本 |
| 3 | 藍(あい) | 演習もできた | `oklch(.45 .11 245)` + 刺し子 2 本 | `oklch(.55 .13 243)` + 刺し子 2 本 |
| 4 | 褐(かち) | 復習をすべて卒業 | `oklch(.24 .06 260)` + 四角の刺し子の目 | `oklch(.5 .13 250)` + 白い太い四角の目 |

- 生成りを塗らないのは、空のマスがチェックボックスや申込用紙の欄に見えないようにするため(枠の実線は入力部品だけが使う)。
- 暗い表示でも「深いほど濃い藍」になるよう、明るさを少しずつ下げる(.6 → .5)。甕覗きは色相 225 の薄い藍(灰色に見えないように)、褐は濃い藍に白い太い目。マスは文字ではない図形なので、地の色と 3:1 以上を下限にする(4.96・4.91・3.99・3.20。`scripts/color_check.py` で検算)。明るい表示の 1 段は地と近いので縁で 3:1 を取る。
- 染めの名前には読みをふりがなで添える(凡例・ヒーロー)
- 2〜4 段には刺し子の目の**形**を入れる(1 本・2 本・四角)。色の差が分からない人にも、暗い表示でも、段の順序が形で読める。
- 凡例は染めの名前(小さく)と意味の二段。レッスン一覧の右には意味の文字(「演習もできた」など)を出す。
- 8 週間の稽古の図は「稽古した回数」なので、染まりの色ではなく `--accent` の濃さだけで描く(染まりの色は染まり具合の意味にだけ使う)。
- 復習の数のバッジは朱。文字は明るい表示で白、暗い表示で地の色(7.3:1)。

- 有彩色は 1 画面で藍と朱の 2 色相まで。朱の塗りは小さい印だけ(連続日数・不正解の印)。
- `opacity` で文字を薄くしない。コントラストは `scripts/color_check.py` で検算する。

### 文字。由来: 道場の札(大きく短く)と、長文を読む教材
- 和文: `"Hiragino Sans", "Hiragino Kaku Gothic ProN", "BIZ UDPGothic", "Yu Gothic UI", "Noto Sans JP", system-ui, sans-serif`(オフラインで確実に出るよう、Web フォントは使わない)
- 等幅: `"Cascadia Code", "SF Mono", Menlo, Consolas, "BIZ UDGothic", monospace`
- 本文 16px(スマホ 17px)/ 行間 1.85 / 字間 0.02em。見出しだけ `palt`。`line-break: strict`、`text-autospace: normal`、`font-synthesis: none`
- サイズの段(px): 12(注記の下限)・14・16(17)・20・24・32・44(ヒーロー)。見出しは本文の 2〜3 倍
- ウェイトは 400 と 700 の 2 段。上下関係は大きさと余白で
- 縦書き(`writing-mode: vertical-rl`)は部の札だけ

### 余白。由来: 畳の目(4px 刻み)
- 4・8・12・16・24・32・48・72・112。外側(節の間)> 内側(見出しと本文)> 部品の中
- スマホの左右は 20px(本文)、全幅の藍の面は端まで

### 角・影・線。由来: 布(角は少し丸い)と拡散光(影はほぼ無い)
- 角丸: 小 4px(印・チップ)、中 8px(ボタン・入力)、大 14px(面)。子は親以下
- 影は浮いているもの(下部ナビ・シート・トースト)だけ。2 層、色は紺寄り
- 区切りは刺し子: `--stitch`(線の長さ 9px・間 6px、太さ 2px、角は丸い)。罫線の代わりに節の区切りと進み具合に使う
- フォーカスは 3px の藍の輪(`outline-offset: 2px`)

### 動き。由来: 藍が布に染み込む
- 署名の動き「染み込み」: 状態が深まった瞬間だけ、**押したボタンのそば**で、古い色のマスの上に新しい色が中心から円く広がって止まる(28px、560ms、120ms 遅らせて始める、`cubic-bezier(.22,1,.36,1)`)。使うのは ①読了 ②クイズ合格 ③演習の「できた」の 3 か所だけ。文字でも「縹に染まった(クイズ合格)」と添える
- そのほかは 160ms の ease-out(色・下線)。押下は `scale(.97)` 120ms
- 縫い進む線: 段の並びの下端に薄い実線を 1 本引き、レッスン本体(最初の段の先頭〜最後の段の末尾)を読んだ割合だけ、藍の刺し子が見えていく。縫い目の長さは変えず、見える範囲(`clip-path`)だけ広げる(布を縫い進むのと同じで、目が伸び縮みしない)
- 段の並びは今読んでいる段に `aria-current` と藍の下線を付け、横に並んだ中で見える位置まで送る
- スマホの質問ボタンは段の並び(sticky)の右端に「質問」の文字つきで置く。本文の上に浮かせない(開いた直後も、戻ったときも文字を隠さないように)。その左に「段の一覧(いま n / 全部)」を置き、横に並びきらない段へも直接飛べるようにする
- 段の順は染まりの順: 読む → 仕事のコード → 見る(PC は動かす)→ 確かめる → 読解 → 書く → STSで試す。スマホは実行できないので「見る」、PC は実行できるので「動かす」と、できることに合わせて名前を変える
- レッスン中は下のメニューのどれも選ばない(ホームを開いているわけではないので)
- 段の「済み」はレ点(縹のマスは「クイズ合格」と紛らわしいので使わない)。仕事のコード・見るは段の最後まで読んだら済み。パソコンでしかできない段(STSで試す)には「PC」の札
- クイズは回答欄にそのまま正誤と解説を出し、結果の欄は点数・染まり・間違えた問へのリンク・次の一手(書くへ進む / もう一度解く)だけ。採点後は答えを止め、「もう一度解く」で元に戻す
- `prefers-reduced-motion: reduce` のときは JS のスクロールも即時にする
- `prefers-reduced-motion: reduce` ではすべて止める

### 下限(割らない)
- 本文 16px、補助 12px 以上。文字は 4.5:1 以上(大きい文字 3:1)。押せる所は 44×44px 以上
- 入力欄は 16px 以上(iOS の拡大を防ぐ)
- 絵文字をアイコンに使わない(1 セットの線のアイコンを inline SVG で、線 1.75px)

### コード
- 読解と「仕事のコード」は**横に流さず折り返す**。行番号を左に付け、説明のある行は番号を藍の札にして、行の背景を少し明るくする(下の「n 行」の説明と同じ番号)
- 折り返した行は行番号の列より右から始まるので、行の頭が見分けられる
- クイズの問題・答え・復習のコードも読むためのものなので折り返す
- スマホでは、仕事のコードの説明をその行の直後に挟む(下の説明まで往復しない)。PC は下にまとめる
- スマホのコードは 14px。深い字下げは 8 文字で止め、続きの行の始まりが右に寄りすぎないようにする
- 例外名のような長い英字は単語の途中で切らない。`.` `(` `,` の後ろと、小文字→大文字の境目に折り返しの候補を入れる
- サンプルと演習、本文の例のコードは、書き写す・実行するものなので折り返さない(横にスクロール)

### ホーム
- 主役は「前回の続き」(最後まで読み切っていないレッスン。段と、段の先頭からの距離で覚えた位置まで戻る。画面を離れるときに位置を確定する)。読み切ったら次の新しいレッスン。一覧の札もヒーローと同じ言葉(前回の続き / 次の新しいレッスン)で、強調は主役の 1 行だけ
- ヒーローに「レッスン一覧へ」。「ホーム画面に追加」の案内は畳んで、閉じられる
- PC は前回の続きをこのブラウザに覚え、ダッシュボードの主役を差し替える。差し替えるまでヒーローを隠す(ちらつかないように)
- ヒーローに、いまの染めの名前と次の段へ進む条件(「いま 甕覗き · クイズで 4 問以上取ると縹に」)
- 保存の状態はヒーローの中。Service Worker が制御していて、画面の部品と全レッスンがキャッシュにあるときだけ「保存済み」と言う
- 数字の欄は他の場所に出ない数だけ(次の復習・読解の正解・この 7 日の稽古)。今日の復習がある日は、ヒーローに出ている数と重ならないよう「この先の復習」と次の日付にする
- ホームに戻ったとき、前に見たときより深まったマスだけ染み込ませる

## 5. 自由にするもの(変数)
レイアウト、ホームの構図、レッスンの節の見せ方、図の置き方。

## 6. 案内役の名前
- 案内役は「モカ先輩」と後輩の「ハル」。モカは前の珈琲の世界の名残だが、55 レッスンの会話がこの名前と口調で書かれていて、学習者もこの名前で読み慣れているので残した(名前を変えると、教材とこれまでのチューターの会話の記録がつながらなくなる)。見た目からは珈琲の記号(茶色・カップ・絵文字)を外し、藍の名札だけにしてある
- 名札は丸い顔の絵ではなく、文字の札(「モカ」「ハル」)。絵文字や似顔絵は使わない

## 7. 雰囲気の言葉
静か・誠実・積み重ね・手仕事・清潔。賑やかさ・ゲームっぽさ・高級ぶりは出さない。
